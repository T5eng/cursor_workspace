# 与原版 Balatro 的差异对照

本仓库目标是 **核心玩法对齐** 的 Web 复刻；下列内容在最新版本中已实现或仍与 Steam 版有差距。

## 已实现（核心循环）

| 系统 | 状态 |
|------|------|
| 筹码 × 倍数计分、9+ 牌型基础值与升级曲线 | ✅ 对齐 wiki 基础值 |
| 皇家同花顺、隐藏牌型（五条 / 同花葫芦 / 同花五条） | ✅ 打出后解锁 |
| 8 个 Ante、小/大/Boss 分数倍率 (1× / 1.5× / Boss 可变) | ✅ |
| **盲注三选一**、小/大盲可 **跳过换 Tag** | ✅ |
| **Boss 盲注**（17+ 常规 + 3 终局）及回合 debuff | ✅ 子集 |
| 弃牌堆 **洗牌重抽** | ✅ |
| **结算界面** → 商店（盲注奖 + 剩余手牌 + 利息） | ✅ |
| 商店：**星球牌**升级指定牌型、小丑重抽、出售/拖拽排序 | ✅ |
| 24 张经典小丑 + Blueprint 复制 | ✅ |

## 仍未复刻（完整版体量）

| 系统 | 说明 |
|------|------|
| **150+ 小丑** | 当前 24 张，缺 Retrigger、经济、改规则等大量卡 |
| **塔罗 / 幻灵 / 优惠券 / 补充包** | 无开包选 1、无改牌面/增强/版本 |
| **卡牌增强** | 无 Bonus/Mult/Glass/Steel/Stone/Wild/Lucky、无 Foil/Holo/Polychrome |
| **牌组编辑** | 固定 52 张，不能删牌加牌 |
| **筹码与难度（Stake）** | 仅白注难度曲线 |
| **标签全集** | 6 种简化 Tag，非完整 Tag 池 |
| **Voucher 科技树** | 无 |
| **Four Fingers / Splash 等** | 顺子/同花仍须 **恰好 5 张** |
| **无尽模式** | 通关 Ante 8 即胜利，无 Endless |
| **存档 / 种子 / 每日挑战** | 无 |
| **Boss 全特效** | 如 The House 暗牌、The Serpent 抽 3 张等未实现 |

若要继续逼近完整版，建议顺序：**塔罗改牌 → 增强/版本 → 扩小丑池 → Voucher → 多牌组**。
