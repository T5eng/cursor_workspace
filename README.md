# 小丑牌 · Joker Cards

一个受 *Balatro* 启发的扑克 Roguelike 小游戏，纯前端 (HTML/CSS/原生 JS)，
可以直接在 Mac 上用浏览器打开就玩，没有任何依赖、没有任何账号、没有任何打包步骤。

> ♠ ♥ ♦ ♣ 出牌、买小丑、堆 combo、连过 8 关。

A 股 / 港股 / 美股日内做T点位分析工具：输入股票代码，基于腾讯财经分时数据，综合 RSI、VWAP、布林带、枢轴点等指标，标注低吸/高抛信号与关键价位。纯前端，无后端依赖。

### LLM 对手（德州）

- 支持 OpenAI 兼容端点：OpenAI、OpenRouter、Groq、DeepSeek、自定义 Base URL

- **注意**：许多 API 禁止浏览器跨域 (CORS)；推荐 [OpenRouter](https://openrouter.ai/) 或自建反向代理并填「自定义」Base URL

## 在 Mac 上启动（任选一种）

### 方法 1：直接双击 `index.html`

```bash
open index.html
```

> 因为没有任何 ES 模块加载需要走 HTTP，所有现代浏览器都能直接 `file://` 打开。
> 如果你的浏览器对本地 `type="module"` 有限制（比如旧版 Safari），可以用方法 2。

### 方法 2：起一个临时 HTTP 服务

任意一条命令都行，访问 http://localhost:8080 即可：

```bash
# Python 3 自带
python3 -m http.server 8080

# 或者 Node（需要全局装一次 serve）
npx --yes serve -l 8080 .
```

### 手机访问

游戏已适配手机浏览器（触控、竖屏布局、底部出牌栏）。与电脑在同一 Wi‑Fi 时：

```bash
# 监听所有网卡，手机才能连进来
python3 -m http.server 8080 --bind 0.0.0.0
```

1. 在 Mac 上查局域网 IP：`ipconfig getifaddr en0`（或系统设置 → 网络）
2. 手机浏览器打开：`http://<你的Mac的IP>:8080`

> 部署到 GitHub Pages / 任意 HTTPS 站点后，也可直接用手机打开链接游玩。

### 方法 3：包成 Mac App（可选）

如果你想要"原生 App 图标"的感觉，最简单的做法是把这个目录拖进 Safari，
然后用 *文件 → 添加到程序坞* 或者用任何把网页打包成 `.app` 的小工具
（例如 [Coherence](https://www.bzgapps.com/coherencex) 或 `nativefier`）。
游戏本体保持纯 web 即可，跨平台。

## 新手教程

首次打开会看到欢迎界面，点击 **「新手教程」** 进入约 13 步的交互引导：

| 步骤 | 内容 |
|------|------|
| 1–4 | 界面导览：盲注目标、手牌/弃牌次数、筹码×倍数公式 |
| 5–6 | **实操**：选中两张 A 组成对子并出牌计分 |
| 7 | 计分流程小结 |
| 8 | **实操**：弃掉 2 和 3 换牌 |
| 9–10 | 装备「小丑」后再出一手，感受 +4 倍数 |
| 11–12 | 击败盲注与商店购买说明 |
| 13 | 完成，进入正式游戏 |

游戏中随时可点顶部 **「教程」** 按钮重温。教程进度保存在浏览器 `localStorage`。

## 玩法速览

| 元素 | 说明 |
|------|------|
| **8 张手牌** | 每轮一开始抽 8 张，可以选 1–5 张组成扑克牌型 |
| **筹码 × 倍数** | 最终得分 = (所有计分牌的筹码相加) × 倍数 |
| **手牌等级** | 商店里的"升级券"能永久提升某种牌型的基础筹码 / 倍数 |
| **小丑** | 装备后会改变计分规则，是堆 combo 的核心 |
| **盲注** | 每关 3 个：小盲 → 大盲 → BOSS，分数达标即可过关 |
| **资金 / 利息** | 击败盲注得金币；身上每 \$5 闲钱每轮回利 \$1（上限 \$5） |
| **目标** | 击败第 8 关的 BOSS 即获胜 |

### 操作

* **点击 / 触摸** 一张手牌 = 选中 / 取消选中（最多 5 张）
* **`Space` / `Enter`** = 出牌（桌面）
* **`Backspace` / `D`** = 弃牌（桌面）
* **手机**：使用屏幕底部 **出牌 / 弃牌** 按钮
* 顶部 **按点数 / 按花色** 按钮可以排序手牌

### 牌型（含基础筹码 × 倍数）

| 中文 | 英文 | 基础筹码 | 倍数 |
|------|------|---------|------|
| 高牌 | High Card | 5 | 1 |
| 对子 | Pair | 10 | 2 |
| 两对 | Two Pair | 20 | 2 |
| 三条 | Three of a Kind | 30 | 3 |
| 顺子 | Straight | 30 | 4 |
| 同花 | Flush | 35 | 4 |
| 葫芦 | Full House | 40 | 4 |
| 四条 | Four of a Kind | 60 | 7 |
| 同花顺 | Straight Flush | 100 | 8 |

`A` 的筹码是 11，`J/Q/K` 各 10，数字牌按点数。

### 小丑示例

| 小丑 | 效果 |
|------|------|
| 小丑 (🃏) | +4 倍数 |
| 色欲小丑 (♥) | 每张计分的红心 +3 倍数 |
| 欢乐小丑 (😄) | 牌型包含对子时 +8 倍数 |
| 半个小丑 (◐) | 出牌 ≤ 3 张时 +20 倍数 |
| 学者 (🎓) | 每张计分的 A +20 筹码、+4 倍数 |
| 斐波那契 (φ) | 每张计分的 A/2/3/5/8 +8 倍数 |
| 蓝图 (📐) | 复制紧邻右侧小丑的效果 |
| ... | 共 24+ 种 |

## 目录结构

```
.
├── index.html          # 入口
├── styles.css          # 美术 / 排版 / 动画
├── t-trading/          # 做T量化分析（独立 GitHub Pages 路径）
│   ├── index.html
│   ├── styles.css
│   └── src/            # api / indicators / analyzer / chart
└── src/
    ├── main.js         # 主菜单 / 模式切换
    ├── cards.js        # 牌 / 牌组 / 扑克牌型识别
    ├── jokers.js       # 24 个小丑定义 + 商店抽牌
    ├── scorer.js       # 计分引擎（产生动画事件序列）
    ├── tutorial.js     # 新手教程步骤引擎与引导 UI
    ├── game.js         # 小丑牌游戏循环 / UI 渲染 / 事件
    ├── holdem/         # 德州扑克引擎与 UI
    └── minigames/emperor/  # 嘉靖朝皇帝生存跑团
```

整个游戏不到 ~1500 行，全部使用原生 ES Module，没有任何第三方包。
